# 🚀 Linux Command Speed Test

A modern web app to practice and improve your Linux command-line speed and accuracy through interactive challenges.

---

## 🧠 Overview

This project is a **typing speed test focused on Linux commands**.  
It helps you build muscle memory, increase typing speed, and improve accuracy while working in the terminal.

---

## ✨ Features

- ⏱️ Real-time countdown timer  
- ⚡ Words per second (WPS) tracking  
- 🎯 Accuracy calculation  
- 📊 Progress tracking  
- 🎮 Multiple difficulty levels (Beginner → Advanced)  
- 💻 Terminal-like UI experience  
- 💡 Built-in tips for better performance  

---

## 🖥️ Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS + shadcn/ui
- **Icons:** Lucide React
- **State Management:** React Hooks

---

## 🚀 Getting Started

### 1) Clone the repository

```bash
git clone https://github.com/your-username/linux-command-speed-test.git
cd linux-command-speed-test
```
2) Install dependencies
   pnpm install
   # or
   npm install
   # or
   yarn
   
3) Run the development server
   pnpm dev

4) Open http://localhost:3000 in your browser.

🧩 How It Works
Select difficulty level
Choose challenge duration
Click Confirm
Start typing the displayed Linux commands
Track your performance:
Time left
Speed (WPS)
Accuracy
Progress

🎯 Purpose
The goal of this project is to turn learning Linux commands from passive memorization into active practice.
